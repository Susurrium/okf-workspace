# OKF Workspace 0.9.0

Document imports now save originals into the Vault and synchronize them with
notes through LiveSync. Desktop, phone, and tablet use the same storage path;
the desktop Engine verifies incoming bytes and processes the explicit request.
PDFs and images open through Obsidian's native file viewer.

The import dialog defaults to **save original only**. This action creates a
Source record without a conversion job or parser dependency. Conversion settings
appear only when conversion is selected, and AI note generation requires an
explicit choice. Existing converted text can be reused for generation.

## Components

- Engine 1.12.0
- Dashboard 1.18.0, including mobile support
- Claudian 2.3.6-okf.4, unchanged
- Workspace schema 3

## Reliability and migration

- Requests and receipts record processing choices and results. Repeated scans do
  not create duplicate jobs, and incomplete sync waits for verified originals.
- Raw Sources can be converted later while preserving user metadata and notes.
- Conversion publication keeps referenced images and normalizes asset links;
  successful jobs clean their temporary working files.
- Migration preserves legacy originals and recovers pending mobile uploads into
  the Vault. Legacy file-service resources remain available for recovery only.

## Deployment

The normal workflow requires LiveSync with a file limit of at least 64 MiB and
without excluding `sources/originals/`. No separate original-file service is
required. Mobile devices must finish plugin synchronization and restart Obsidian
to load Dashboard 1.18.0. Desktop Obsidian must run for Engine processing.

Back up the Vault, State, and legacy Originals before migration. Follow
[original storage and migration](../DEPLOYMENT.md#original-migration) and
[mobile intake](../USER-GUIDE.md#手机和平板阅读). Existing user or test content is
preserved during upgrade.
