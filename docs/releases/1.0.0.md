# OKF Workspace 1.0.0

发布日期：2026-10-17。正式版整合工作台、Vault 原件与资料处理、学习与项目流程，以及内嵌 Codex 会话。

| 项目 | 版本 |
| --- | --- |
| Workspace | 1.0.0 |
| Workspace schema | 3 |
| Engine | 1.12.0 |
| Dashboard | 1.18.0 |
| Claudian | 2.3.6-okf.5 |

## 功能

- 工作台支持普通布局与沉浸布局、分区与小组件添加、顶部快速记录，以及多个入口共享草稿。
- 课程、项目、资料、学习笔记、知识笔记与任务共用 Vault 中的 Markdown/YAML；支持课程与项目双关联、项目类别和来源跳转。
- 原件按内容哈希保存在 Vault，可明确选择保存或转换；支持 MinerU 云端、MarkItDown 与可选自建 MinerU。
- Today 展示中国热点、AI 资讯和树洞热榜；Reading 支持来源、历史期次、论文与人工资料用途判断。
- Claudian 通过 `okfBridge v1` 接收上下文和动作模式，使用本机 Codex；后台生成保留实际读取记录，学习完成由用户明确确认。
- Windows 完整版本包包含 Engine wheel、带哈希的依赖锁、两套插件成品、安装器与运维脚本，并提供文件清单和 ZIP 校验值。
