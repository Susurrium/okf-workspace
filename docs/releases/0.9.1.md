# OKF Workspace 0.9.1

Claudian dependency maintenance fixes known issues in URI host parsing and IPv6
link-local classification. The release also scopes the test tooling's YAML
parser to its compatible patched major version and removes obsolete browser
data overrides.

## Changes

- Upgrade `fast-uri` from 3.1.6 to 3.1.8, including the newer host-normalization
  fix ([advisory](https://github.com/advisories/GHSA-hrr3-gc8f-f4qj)).
- Upgrade `ip-address` from 10.3.1 to 10.7.3, including newer subnet comparison
  and diagnostic length fixes
  ([advisory](https://github.com/advisories/GHSA-j6r3-76f7-8jcv)).
- Refresh the compatible `proxy-addr` resolution to 2.0.8
  ([advisory](https://github.com/advisories/GHSA-jqcg-44mw-7w3h)).
- Upgrade `smol-toml` from 1.7.1 to 1.9.0 to fix quadratic parse time
  ([advisory](https://github.com/advisories/GHSA-r4xh-jqrq-34v2)).
- Scope `js-yaml` 3.15.2 to `@istanbuljs/load-nyc-config`, retaining the global
  patched 4.3.2 override
  ([advisory](https://github.com/advisories/GHSA-2883-xcg3-v3hh)).
- Remove forced `browserslist` and `baseline-browser-mapping` versions while
  retaining reproducible resolutions in the lockfile.
- Preserve CodeMirror alignment and the remaining dependency overrides.

## Audit scope

On 2026-10-06, `npm audit --omit=dev` reported zero production dependency
vulnerabilities after these updates. The full audit still reported 31 affected
development dependency entries (24 moderate, 7 high), including propagated
reports through test, lint, and Obsidian SDK tooling. This release does not claim
that the complete development dependency tree is advisory-free.

## Components and upgrade

- Engine 1.12.0
- Dashboard 1.18.0
- Claudian 2.3.6-okf.5
- Workspace schema 3

Install the updated Claudian plugin files and reload Obsidian. Engine and
Dashboard archives are identical to their 0.9.0 release assets. This maintenance
release does not require a Vault data migration.
