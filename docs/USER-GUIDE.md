# 工作台使用指南

[文档入口](../README.md#文档入口) · [安装与配置](DEPLOYMENT.md)

| 想做什么 | 入口 |
| --- | --- |
| 记录想法 | “快速记录”，保存到收集箱，可关联课程和项目 |
| 写日记或复盘 | “记到今日日记”“新建反思”“新建复盘” |
| 管理任务 | “任务”，按日期、状态、范围或保存视图浏览 |
| 收集文件或网页 | “导入资料”或浏览器 Web Clipper |
| 学习与整理知识 | “学习”生成学习笔记，“知识笔记”查看 Wiki 与导航 |
| 推进项目 | “项目”中的进展、任务、资料、日志及决策 |
| 处理失败 | “后台与诊断”或对象旁的重试入口 |

## 分区与工作台

日常工作台包含今天、便签、每日更新和任务周历；学习、项目、订阅、知识与系统预设组合相应功能。
新建学习或项目工作台时选择总览或具体对象。各业务功能也可通过命令独立打开。

| 分区 | 内容 |
| --- | --- |
| 今天 | 今日与逾期任务、继续工作、人工待处理提醒 |
| 任务 | 来源笔记中的 Tasks 任务、日期、历史与查询 |
| 收集箱 | 随手记录、网页剪藏、未决定用途的资料 |
| 订阅阅读 | 来源、期次、历史与用途判断 |
| 资料 | 已保存资料、原件、正文、用途和关联成果 |
| 学习 | 待准备、可学习、已学完，按课程、项目或独立范围浏览 |
| 项目 | 状态、任务、进展、日志、决策与成果 |
| 知识笔记 | Wiki、知识导航及维护状态 |
| 日记与复盘 | 日记、反思和周期复盘 |
| 后台与诊断 | 执行与恢复、运行环境诊断 |

添加分区时可搜索类型；便签、清单、便利贴和手工笔记卡片分别保留。便利贴可混放便签与清单。
右缘短线用于分区定位，悬停显示名称，Tab 后按 Enter/空格也可定位，触屏常显。

内容工具栏提供新建、搜索、筛选、排序与视图切换；标题菜单提供设置、重命名和移除。
分区设置中的范围、初始视图和默认排序长期保存；页内临时筛选与排序分别记忆。
固定范围与临时筛选共同生效。业务目录默认每批 10 项，独立页面每批 30 项；订阅来源每批最多 8 个，
各工具保留自己的分页设置。资料目录每份资料显示一次，收集箱按待判断的用途上下文显示。

标题栏可折叠、刷新或在新标签页打开当前视图。功能分区、日历、属性/文件夹视图、图片、视频和 DQL
提供独立页面；卡片、微信读书和滴答清单提供放大窗口，网页可在浏览器打开。
独立页面携带当前范围、查询、排序与视图，之后分别保存浏览位置；解除范围不修改原工作台。

打开旧工作台只读取；保存设置保留其他分区、未知配置、正文和已有布局。旧预设继续保留。

### 布局与沉浸式工作台

右键当前工作台编号选择“跟随默认布局”“小组件在左”“小组件在上”或“沉浸式自由布局”。
每个工作台分别保存选择；编号旁的加号可用本地预设和课程/项目上下文新建工作台。

沉浸式的时钟和操作条位于网格上方，随整页滚动。分区初始占半行宽，高度按内容适配；
手动缩放后保留高度，长内容可在分区内滚动。拖动标题或小组件顶部移动位置，落点预览显示结果；
拖动右边、底边或右下角调整尺寸，松开自动保存，窗口失焦取消。

操作条加号中，“添加分区”单独成组；分隔线后是“备忘录卡片”“待办清单卡片”和小组件。
两种卡片每次添加一张，缺少便利贴分区时自动创建。已加入当前工作台的组件禁用重复添加，也可创建相册、倒计时与纪念日实例。沉浸式按工作台添加组件；
左右/上下布局由全局开关控制。组件关闭按钮或右键菜单仅将它移出当前工作台，配置继续保留，可再次添加。
便利贴逐卡显示，普通备忘录与清单维持原有组织。

窄于 640px 时单列阅读，保留宽窗格坐标与尺寸；扩大后继续调整。手机使用小组件在左的布局。
布局保存失败时保留预览，使用“重试保存”或“重新读取”；同一卡片的并发冲突需重新读取后处理。

### 常用操作条

设置中的“常用操作 → 配置”可添加创建按钮、置顶笔记、快捷命令和今日日记入口，分别用于按模板新建笔记、
打开指定笔记、执行 Obsidian 命令及打开今日日记。图标和名称由配置决定；网格里的“快捷按钮”卡片通过卡片自身入口配置。

### 外观与小组件

没有保存固定偏好时侧栏默认固定，可用横幅图钉取消。命令“打开外观工作室”调整配色、背景、透明度、
模糊、圆角和字号；“保存为主题”保存完整外观，删除主题保留当前显示。

番茄钟齿轮设置倒计时/正计时、提醒、活动标签与背景。正计时排除暂停时间，提醒间隔零表示不提醒；
关闭提醒窗口后继续计时，明确“结束并记录”才保存一次，不足一分钟不记录。结束当前计时后才能切换模式。
记账支持分类增删、排序与分组，每个方向至少保留一个分类，删除分类保留流水。
音乐连续失败停止时提示；迷你计时条与当前计时同步。

## 记录与日记

### 快速记录

顶部、侧栏和网格快速记录共享默认草稿及展开编辑；操作条随顶部滚动，小组件随卡片排列。
沉浸式时钟下依次显示已启用的输入条、已配置的快捷操作和网格；仅启用输入框时省去空快捷行。
“常用操作条”总开关控制整个顶部操作条，“顶部快速记录”控制其中的输入框；关闭总开关保留输入框选择。
“侧栏快速记录”独立控制侧栏输入组件，沉浸式网格输入组件由当前工作台的组件成员控制。
仅首次安装且无旧配置可导入时默认开启顶部操作条和输入框；已有配置保留兼容默认值与明确保存的关闭选择。
设置开关保存失败时提示并恢复原值；配置窗口保存失败保留编辑与窗口，可继续重试。
Enter 保存、Shift+Enter 换行，手机使用保存按钮。“展开”编辑同一草稿，可同时关联课程和项目，
Ctrl+Enter 保存，关闭保留草稿。命令和上下文入口共用提交流程；课程/项目入口预填关联。

每次提交生成一篇随手记录并进入收集箱。默认与不同上下文的草稿分别保留，同一草稿在多个窗口同步。
写入失败保留输入；文件已创建后的重试继续原提交。侧栏固定时省去默认的重复快捷按钮，自定义按钮和命令保留。
旧版普通闪念笔记保持原位置。工作台便签可通过“移到待处理”转为随手记录并移除原便签。

### 日记、反思与复盘

“记到今日日记”直接打开当天原生日记的随手记录区。新建反思输入标题后打开正文；
“新建复盘”选择 Weekly/Monthly/Yearly，创建或打开当期复盘。人工原文与个人补充保持不变，
需要整理时可说“使用 `$organize-daily` 整理今天的记录”。

| 内容 | 保存位置 |
| --- | --- |
| 随手记录 | `inbox/captures/YYYY/MM/` |
| 日记、反思、复盘 | `life/daily/`、`life/reflections/`、`life/reviews/` |
| 课堂笔记 | 对应课程的 `lessons/`，原文写在 notes 区 |
| 项目当前状态与过程 | 项目的 `project.md` 和连续日志 `log.md` |
| 正式项目决策 | 项目的 `decisions/` |
| 知识笔记与导航 | `knowledge/wiki/`、`knowledge/maps/` |

## 任务

普通笔记任务使用内嵌 Tasks；识别遵循用户的全局过滤、格式、状态顺序和编辑设置。
例如全局过滤为 `#task` 时写 `- [ ] #task 完成一个明确动作`。
工作台清单在所属卡片中管理层级、勾选、折叠、拖动、模板、提醒和进度，日期或循环文字保持简单勾选语义；
工作台及安全副本、资料、代码示例和系统派生视图排除在正式任务统计之外。

任务页提供全部未完成、今日、逾期、后续、无日期、完成/取消历史、自定义查询和保存视图。
日期、课程/项目与高级查询取交集，查询错误直接显示。“后续”可与今日重叠；“无日期”表示未设置任何任务日期或提醒。

| 操作 | 行为 |
| --- | --- |
| 编辑 | 点击文字或日期；取消不保存，失败保留输入；新建后刷新失败时重试复用原任务 |
| 来源与日记 | 定位来源真实行；“加入当日日记”保存引用，“复制为独立日记任务”建立新身份并重映射内部依赖 |
| 移动与归档 | 保留完整子树、身份、日期和扩展字段并更新引用；并发变化时停止覆盖；清单归档写回所属工作台 |
| 保存视图 | 保存查询与范围，可改名、更新和删除；临时筛选独立记忆 |
| 提醒 | 同一任务各入口共享提醒；已确认提醒在重启或移动后不重复，重新安排时间产生新提醒；运行时检查，重启发现到期未确认提醒 |

循环任务按设置保留执行记录并生成后续项，提醒随日期偏移。任务默认不从日记文件名推断日期，可在设置开启。
日历默认创建计划日期，显示保存位置并分别记忆筛选；日列表每任务一次，时间网格分别显示不同日期事件。
课程和项目可同时关联，上下文入口预填范围。

首次接管保留独立 Tasks 设置文件，优先使用 Dashboard 设置；独立插件运行时由“使用内置 Tasks”切换写入服务。
“检查任务范围与历史配置”只读列出差异和来源。实际内容迁移需明确执行。

## 资料与网页剪藏

### 导入资料

电脑、手机和平板使用同一窗口；电脑可拖入文件或文件夹，单文件上限 64 MiB。
文件夹仅用于批量选择。检查文件、跳过项与课程/项目归属后提交；窗口在当前插件会话保留选择，重启后重新选择未保存文件。

默认“仅保存原件”：先保存到本机 `sources/originals/<sha256>/<原文件名>`，断网可用，随后同步并由主机登记资料。
需要 Markdown 时选择“保存并转换正文”，指定转换方式、质量检查、用途和归属。
默认 MinerU 云解析，其他方式需已配置；格式和能力见[部署指南](DEPLOYMENT.md#conversion)。
严格图片检查不改变解析能力，扫描件、复杂公式和图示需核对原件。

只关联或选择用途不会自动启动 AI；“现在生成”才创建后台任务，“稍后生成”只保存用途。
同一原件复用资料身份并保留不同用途。资料卡可打开原件、正文和本次转换结果，也可单独重试失败的生成。
重新转换需等待当前执行结束，可明确更换方式；正文有人工修改时保留原文，新结果可只读查看。

### 网页剪藏

1. 安装官方 Obsidian Web Clipper，将当前 Vault 设为目标。
2. 在 Templates 中导入 `system/integrations/web-clipper/workspace-web-capture.json`，将模板置于顶部；保留其 HTTP/HTTPS 触发器。
3. 关闭 Interpreter。模板更新后重新导入；浏览器扩展设置不随 Vault 同步。

模板将全文、选区或高亮保存到收集箱，不使用本地服务 token 或 AI。在“网页剪藏”中选择立即学习、
稍后学习、生成知识笔记、仅作参考或丢弃；不操作则继续保留。
相同 URL 的内容与订阅资料去重，图片先保留远程链接，再后台下载；失败保留链接。
旧默认 `Clippings/` 模板笔记的迁移规则见[接口说明](INTERFACES.md#web-clipper)。

### 手机和平板阅读

开启设备所需网络连接与 LiveSync，等待笔记和原件同步。PDF、图片由 Obsidian 原生打开，未到达时提示等待；
Office 文件可阅读转换正文。批注或改版另存后重新导入，保留哈希归档原件。
普通附件“导入为资料”保留原位置和已有嵌入链接。

升级旧设备前先完成[原件迁移](DEPLOYMENT.md#original-migration)。插件程序与设备设置分开同步，
保留本机路径和凭据；旧上传恢复失败时保留数据并提供重试。

## 订阅阅读

每日更新显示中国热点、AI 资讯和树洞热榜，各自选择最近一期；原始正文打开原生订阅汇总。
订阅阅读按来源浏览最新摘要，支持搜索、分页、进入来源查看历史和返回位置恢复。
顶部 AI Papers 是独立系统卡片；普通订阅先预览再确认添加，停用或移除停止后续采集并保留历史。

浏览不会创建资料或学习笔记。由你选择现在学习、稍后学习、形成知识笔记、仅作参考或不保留；
也可直接离开继续保留候选。同一资料可用于不同课程或项目。正文、评论与判断复用原生订阅汇总中的同一条目。

## 学习与知识

1. 在学习页选择后台生成或在 Codex 中生成；后者附带来源和 `$prepare-study-guide`，可补充要求后发送。
2. 阅读学习笔记，结合原件讨论；需保存讨论成果时使用 `$update-study-guide` 增量完善。
3. 明确学完后标记完成，或说明“使用 `$distill-wiki` 整理为知识笔记；我已经完成学习”。
4. 直接从资料整理知识也使用 `$distill-wiki`；需要主题导航时使用 `$maintain-wiki-map`。

生成、打开和讨论均不自动记录学完。后台仅修改允许的 AI 区域；个人补充写在普通正文或人工区域。
新对话需要既有知识时使用 `$retrieve-vault-context`，检索定位后读取真实笔记。

## 项目

创建项目时填写目标、约束和计划，可选择一个主类别，留空为“未分类”。类别入口支持选择、输入或清除；
“管理类别”覆盖已完成和暂停项目，改名/合并前显示影响列表，失败逐项列出并保护期间的人工修改。

目录支持类别筛选、状态/类别分组、列表/看板及各组加载更多。置顶和手动顺序属于当前视图；
拖动“拖到其他分组”修改类别或状态，键盘/触屏也可通过相应窗口操作。改变类别保留笔记路径及关联内容。

项目行提供当前常用动作；其他菜单提供日志、待整理想法、资料、决策和 AI 整理。
“项目日志”留空打开 `log.md`，填写则按时间追加。需要整理进展时使用 `$capture-project-progress`，
追加过程并按需更新当前状态；正式决定再建独立决策笔记。

## 插件与诊断

Vault 根 `index.md` 是插件不可用时的导航。Templater 可从 `system/templates/interactive/` 创建反思、复盘或项目更新；
同周期复盘已存在时从工作台打开。日记共用 Core Daily Notes 模板；Chinese Calendar 调用同一路径。
QuickAdd 可绑定“统一 OKF 快捷动作菜单”，Dataview 可浏览 `system/views/Learning.md`、`Projects.md`，Recent Files 提供侧栏历史。

### Claudian

工作台交接打开可见 Codex 会话，任务与附件可检查、移除或补充，默认预填后由你发送。
资料卡与资料正文分别显示附件，生成期间可点“停止”。访问权限由设置决定，计划模式的具体限制见[接口说明](INTERFACES.md#bridge)。

“后台与诊断”显示执行阶段、失败和恢复入口，以及服务、解析器、Codex、索引、Contract、断链与知识维护问题。
阅读和人工编辑本地 Markdown 可离线进行；登记、转换、后台生成和主机索引需主机 Engine 运行。
Vault Git checkpoint 与备份按需启用，配置和恢复见[部署指南](DEPLOYMENT.md#sync-backup)。
