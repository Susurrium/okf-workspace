# 手机 / 平板导入与阅读

所有原件保存在 Vault 的 `sources/originals/`，与 Markdown 使用同一套 LiveSync 全量同步。

1. 在工作台选择“导入资料”，选文件和归属。默认“仅保存原件”，点击“保存原件”。需要正文时明确选择“保存并转换正文”；转换设置仅在这个分支显示，生成学习指南或 Wiki 还需额外勾选。
2. 原件立即保存在本机笔记库，可以在 Obsidian 中打开。支持的转换输入为 PDF、Word、PowerPoint 和常见图片，单个文件不超过 64 MiB。
3. 保持 Tailscale 连接与 LiveSync 开启，等待同步完成。本机保存成功不等于服务器已经收到。
4. 电脑 Obsidian 打开、本地 Engine 运行后，登记已保存的原件；只有明确选择转换的请求才进入转换队列。电脑关闭时，已同步的原件仍可阅读。
5. 在“已保存的资料”打开原件、主动转换或查看处理结果。已有正文时，“生成笔记”复用正文，不再转换；生成失败可单独重试。

不再配置原件服务地址、编号、令牌或“保留离线”。文件同步完成后全部留在本机；没有单独的按需缓存和清理按钮。Office 格式可以阅读转换正文，需要编辑时自行选择外部应用。

## 从旧版升级

电脑先迁移已有原件，再通过 LiveSync 发送原件和新版工作台程序。平板完成同步后重启 Obsidian，使新版生效。如果隐藏程序未自动更新，在 LiveSync 的 Hidden Files 功能取回最新工作台插件文件，再重启。

只同步插件 `main.js`、`manifest.json` 和 `styles.css`；不覆盖设备自己的 `data.json`、本地路径或密钥。新版启动时恢复旧设备待上传字节；发生问题会保留数据，并在已提交列表显示“重试恢复旧版文件”。

完整路径、迁移边界和验证见 [原件全量同步](ORIGINAL-FILES.md)。
