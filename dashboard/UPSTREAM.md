通用接入修改须兼容默认上游宿主，不从子树直接导入 OKF 领域模块。完整导入版本与选择性移植范围分别记录。

## 上游采用策略

### 采用范围

| 范围 | 本地采用与边界 |
| --- | --- |
| 通用修复 | 微信读书请求版本 1.0.5、当前组件界面/拖动稳定性、完整原生图标选择、分区导航、无偏好时默认固定侧栏、移除备忘录改色按钮、减少音乐逐曲失败通知 |
| 外观 | 自定义主题保存与外观工作室命令、胶囊和抹茶暗色；新增胶囊并保留丁香及原有选择，保留滚动条策略 |
| 番茄钟 | 正计时、提醒和统一设置；统一插件路径、多 pane 订阅、提醒取消与明确保存/失败反馈 |
| 记账 | 分类管理采用 version 2 单一清单；按无正式历史数据设计，不开发旧格式迁移、推断、双写或主动删文件，未知格式拒绝覆盖 |
| 快速记录 | 顶部和组件输入接入统一 Capture；宿主托管草稿、关联、保存与重试，显示设置通过事务保存并回读核验；OKF 不提供独立闪念目标/文件夹/模板配置，旧配置保留，独立上游宿主保持原捕获方式；操作和初始化规则见使用指南 |
| 项目 | OKF 类别、分组、看板、置顶和手动排列；类别进入 Project Contract，复用现有读写，不导入上游独立 PM 模型及生命周期 |
| 沉浸式 | 移植 3.8.5 的 `immersive.ts`、`immersive-grid.ts`、样式、共享组件构建和验收脚本；两个核心包含本地适配 |

沉浸式适配现有宿主、稳定分区 ID、Capture 会话、本地预设与上下文、业务分区和共享组件服务，
保留 memo/todo/sticky 的数据语义。本地修正包括首次列宽/业务高度测量、缩放边界、防重叠、
拖动取消、资源清理、并发保护、保存重试、按钮对比度和窄窗格展示。
添加菜单将分区入口独立成组，单卡入口与小组件放在分隔线后；组件目录次序和重复添加限制沿用既有规则。
操作说明见[使用指南](../docs/USER-GUIDE.md#布局与沉浸式工作台)，数据规则见[工作台布局](../docs/architecture/README.md#工作台布局)。

### 明确排除

- 上游 RSS 阅读器、全文提取、OPML、文章保存及专用缓存。
- 内容工作流看板。
- Apex 技能库、技能按钮、快捷调用、自动发现、GitHub 导入及按钮换行。
- Codex Desktop、Copilot、ZCode、WorkBuddy 等新增调度入口。
- 文件搜索小组件及操作条输入用途切换。
- 分组渲染上限从 2000 降至 500，以及新增隐藏滚动条规则。
- 上游独立 PM 模型的创建/归档/删除，以及自行实现的任务勾选/重命名/排序。
- Claudian 内部接口、作者个人 PARA 字段、新功能固定使用 `apex-dashboard` 数据目录。
- 自动将旧 memo/todo 转为 sticky，或以上游固定分区、创建接口和默认模板替换本地实现。

后续审查默认跳过排除项，不补入口、配置、依赖或适配；只有用户明确改变范围才重新纳入。
共享文件继续检查对当前组件有效的独立修复。现有 OKF 订阅、项目、Tasks、公开 Bridge 与 Vault 规则按各自职责维护。

## 更新与验证

1. 固定候选版本/提交，按以上采用范围逐项比较；完整子树更新须明确允许全部行为变化。
2. 检查 parser/serializer、分区菜单、任务/日期、Daily 路由、数据库编辑、数据路径、设置及服务生命周期，保留未知字段和用户内容。
3. 执行[开发指南](../docs/DEVELOPMENT.md#检查与构建)要求的 Apex、Dashboard、共享夹具与固定测试 Vault 验收，记录实际产物和退出状态。
4. 更新本页的来源/采用范围及[验收台账](ACCEPTANCE.md)。逐功能来源提交和历史修正用 Git 历史查阅。

注册表恢复与布局兼容见[架构](../docs/architecture/README.md#任务与工作台)，回归入口为 `dashboard/tests/workspace-recovery.test.ts`。
